# Beta 0.26.1c
Four advanced visuals: 3x3 intended target accuracy and actual location frequency, pitch-type exact location and in-zone percentages, eight historical weekly uncoupled ACWR snapshots, past assignment adherence by activity. New accepted game results retain bounded pitch detail (max 50 per session, latest 1000 sessions per player); older summaries remain intact and are excluded from detail-only calculations. Robot geometric target matches differ from reward hits; mixed games and ball sizes are not standardized tests. Outside intended targets excluded from 3x3 target grid; outside actual pitches included in distribution denominator. CPU throws excluded. ACWR gaps are not interpolated. Adherence reports logged, not logged and review conflicts; not proof of compliance. No new physical workload prescriptions or scoring changes. Local beta only, actual device rendering unverified.
Optional location review cue is shown only when a location has at least ten observed attempts. No extra throws suggested. Distribution colors indicate frequency, not quality.
