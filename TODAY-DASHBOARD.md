# Beta 0.26.2b.4
One team table: safety stop first, new check-in/changed throwing records/pending assignment next, remaining athletes alphabetically. Persisted information-review snapshot independent of training approval. Existing records without a review snapshot flagged; rolling day changes alone do not create new throws. New or edited external entries and changed 35-day totals trigger review. Identical repeated check-in submissions not distinguished. Links open selected athlete details; edit today in modal, optional explicit wellness acknowledgment, latest-record and assignment validation. No cloud sync or secure authentication. Browser testing outstanding.
Team filter wired to refresh; returning to the page or a storage event refreshes the roster. The editor rejects changes in schedule/review snapshot as well as throwing/check-in changes while open. Information review is independent of calendar approval: first-time historical records may be flagged even if a coach previously built a schedule, because no previous information-review baseline was recorded.
