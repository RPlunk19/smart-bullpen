# Beta 0.16 — Design Lab
Experimental standalone WebGL test page. Existing game engines, settings, player storage, rewards, and 2D/Canvas rendering are unchanged; only home navigation adds a link. No software installation required for users. 
## Dependency
Vendored Three.js r180 (MIT): https://github.com/mrdoob/three.js/tree/r180 . The two minified build modules and license are copied from the tagged source; GLTFLoader and BufferGeometryUtils have their bare three import redirected to the local module. r180 is a pinned baseline, not the latest release (r187 lacked minified distributions in its GitHub build directory). No CDN, analytics, new permissions or uploads. Only the separate lab allows same-origin and data URI asset loading; playable pages retain their existing CSP. A dependency security review and upgrade strategy remain required before public release.
## Scope
Reusable WebGL renderer, perspective camera, standard physically based materials, lighting presets, dynamic shadows, quality levels and explicit model disposal. Articulated prototype Scout and player plus a tiny original glTF crystal proving local model loading. Idle, attack, KO, rotation, pause, reduced-motion and classic fallback. Models are test assets, not production artwork or real skeletal rigs. No player data read or written.
## Verification
Static JS/HTML and glTF buffer checks; browser WebGL, import execution, context loss, actual FPS and phone/tablet testing are outstanding. On iPhone/iPad and desktop, test robot/player/crystal, lighting, rotation, quality, animations, pause, Home, and existing games. Use Low if needed. No athlete throws required.
## Beta 0.17 — Character Studio first pass
Four studio entry points share one renderer: Character (new modular model), Robot (existing Scout prototype), Environment (new harbor blockout), Animation (player motion controls, robot via model selector). No playable game changes. Player appearance reads existing local profile and all 12 equipment slots; previews of locked gear use a temporary copy only. Catalog options share geometry and materials with selected shape differences; not individually hand-modeled assets. Jersey numbers use geometry, no fonts or texture requests. Hierarchical shoulder/elbow/hip/knee joints; stylized idle, throw, celebration, disappointment, attack and KO. Pitch animation is entertainment not coaching. No skeletal skinning, cloth simulation, or full game integration. Existing Three.js version unchanged. Browser testing and dependency review outstanding.
## Beta 0.18 — Character Remastered
Male, female and gender-neutral avatar appearance, independent 0–100 height and build scales with neutral midpoint; avatar choices are cosmetic, not real demographic or weight data. Profiles preserve optional fields through sanitization, equip, accept and reload; existing records default to male (previous visual style) and midpoint scales. No new dependencies.

## Beta 0.20 — Baseball Character & Drip Studio
Builds on approved Quaternius CC0 male/female rigs. Existing 70 items and 12 categories available in read-only preview, independent six hair shapes and eight colors plus custom color, body presets, skin/height/build/number, cap toggle and restore profile. Neutral styling uses masculine base (not third model). Original geometry accessories are anchored using actual head/eye/hand bounds and torso surface triangle sampling; jersey print projected in bind space on the skinned body by a local canvas texture and shader, surface paint for uniform/pants/tape/sleeve/socks/cleats/eye black. Not loose cloth garments or fully unique meshes for each item, and no new baseball pitch motion. Existing classic comparison retained, independent hair changes apply to rigged models only. No writes, no unlocks, no paid assets or external dependencies. Browser shader compilation, accessory fit during movement and mobile performance require testing.
## Beta 0.20.1 — Uniform, glove and cleat refinement
Separate jersey and trouser shells derived from original CC0 body topology, retaining skin indices and weights, with fabric clearance, relaxed shape, small folds, seam and print shader. The original base remains underneath for gap coverage. Fitted shoe uppers/soles, laces, studs, foot-bone attachment from per-model foot bounds. Catalog colors and unlock rules retained, no profile or game changes, no paid assets. Garments are procedural skinned shells, not professionally tailored or simulated cloth; fit, shader appearance and clipping require browser testing.
