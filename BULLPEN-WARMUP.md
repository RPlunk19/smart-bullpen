# Beta 0.25.3
Optional 720-second guided routine (17 steps), illustrated avatar with selected jersey color and skin, phase timers, manual start for each step, pause, extend, skip, sound opt-in, safe throwing guidance and hidden-tab pause. No automatic advancement into throwing. Home card replaces Game Day Prep, which remains under coaching resources. Nonblocking reminders in each game setup, dismissible for the browser tab/day. One preparation credit per player/local calendar day after full timed routine; no streaks, no extra throws or mandatory participation. Three local Clubhouse badges at 1, 10, 25 days. No changes to scoring engines. No medical clearance or injury prevention guarantee; actual device testing required.
The illustrated avatar is procedural 2D rather than a fully rigged exercise animation. The initial Begin button starts the first step; all subsequent steps wait for manual confirmation. Returning from browser history resumes the timer paused. Reminders are once per tab/day, not a claim of readiness.
