# Beta 0.26.2b.1
Weekly calendar defaults to active player and current Monday, with summary, compact assignment rows, direct edit/add modal and collapsed program builder/event sections. Edits affect one assignment only; reusable templates and adjacent days remain intact. Edit game, maximum daily ceiling, familiar pitches, objective and note. Old assignment snapshot checked against latest storage before save. Changed training assignments require fresh personal coach review (not auto-approved); hard restrictions cannot be overridden. Past assignments are not editable via this new editor. Existing game caps remain unchanged, so a ceiling between supported game choices requires choosing a smaller available cap. Mobile browser testing outstanding.
