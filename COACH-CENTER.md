# Beta 0.26 — Coach Center foundation
Local dashboard with per-player saved session summaries from four games (including robot duel), weighted exact and in-zone rates, last 7/30/90 days and recent history, team/player/game filters, weekly trend table, CSV export. No fabricated historical session data. Teams reuse local profiles; assignments by player or team, with logged status based on activity history; no automatic prescription, no mandatory throwing. Additional throws manually logged, no duplicate counting of already saved game pitches. Multi-day tournament match totals flagged and excluded from daily known subtotal; use tournament-specific physical workload records separately. Workload totals incomplete without manual entries. Profile data stays local; no accounts, medical data, cloud, cross-device sync or enforceable coach access. Session history limited to latest 1000 per player; table shows latest 200, export includes full filtered history. Plans and external entries limited to 3000 each on sanitization. Browser rendering/export unverified.
