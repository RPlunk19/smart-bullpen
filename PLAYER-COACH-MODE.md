# Beta 0.26.1a
Player home no longer contains Coach Center or workload analytics cards. Small adult workspace switch near Clubhouse. Coach pages require a session-local mode flag; returning to player clears it. This is navigation separation only, not authentication, authorization, or a secure PIN; browser-local data can be accessed by anyone using the browser. Athlete prompt per active profile per local calendar day on home entry; no new throws, log, or later. No new throws only acknowledges the prompt, never verifies workload or implies a rest day. Simplified outside throwing entry shares coach records, preserves official game pitches separately, combined extra throws classified unknown intensity, invalidates affected day verification. Players can log multiple activities; no advanced workload settings or staff dashboard shown in player UI. Player home displays conservative coach-assignment/rest hints, not automatic clearance. Browser testing required.
Home saves merge the latest coach and tournament state to prevent a subsequent Clubhouse or Crate Crash save from overwriting popup entries. Prompt is once per profile/day after acknowledgement, and dismissal without acknowledgement allows a future visit to prompt again. No daily coverage confirmation is performed by the player prompt.
