# Beta 0.23 — Sniper Bullpen
Six local modes: solo CPU, 1v1, 2v2 CPU, three-way free-for-all, two vs human+CPU, 2v2 humans. Caps 10, 15, 20, 30, 50 per participant, not prescribed workload. Coach confirms remaining allowance; regulation 5 oz and fastball default. Optional small/large 4/5/6 oz are selectable configurations, not claims about supplied Driveline inventory. Three independent virtual dice, 9 catcher-view zones, exact=2/other strike=1/outside=0. CPU simulated by difficulty, manual reveal. Equal turns per participant, team alternation, no extra tie throws. Undo restores call and CPU outcome. Stop produces partial report without win. Individual breakdowns and heatmaps, team points, shared profile statistics and six cosmetic rewards, winner 3D celebration with fallback. No online services, no raw logs persisted. Dice use CSS animation, not WebGL. Browser/device tests remain required.
Custom small/large weights from 3–7 oz can be entered to match actual coach-approved inventory. Corrections must be resolved before stopping or undoing again. CPU results show the actual simulated location.
## Beta 0.23.1
Automatic CPU rolling, simulated pitch and visible result pause; no manual CPU controls. Four difficulty levels with exact/other-strike probabilities 10/35, 25/40, 40/40, 60/30 percent. Graphic vector dice faces show ball size, pitch path, and called zone, with separate explicit text. Human corrections rewind trailing CPU turns and replay their original calls/outcomes. No extra physical pitches.
## Beta 0.23.2
Mirror Match uses intersection of approved implements/pitches, one shared call per round. Career totals and personal bests by cap, format, and regulation/mixed pool; detailed rates begin at this release. Local leaderboard ranks by points then exact hits, ties share rank. Tournament mode supports individual/doubles single elimination (2/4/8 entries) and round robin (2–8), provided worst-case workload fits the confirmed cumulative cap. Regulation fastball only, shared schedule across matches. Elimination ties advance by seed; round-robin standings use 3 win/1 draw, then points, shared titles if tied. Partial match ends tournament and preserves logged workload. Bracket state is session-local, saved match results persist; no reload recovery.
## Beta 0.23.3
Multiple saved named tournaments in the local roster, pitch checkpoints and pause/resume, selectable matches, daily per-athlete approval, cross-tournament daily counts and cumulative workload, archives, JSON backup. Match and career acceptance written together. Imported tournament backups require matching profile IDs, do not import prior rewards, reset daily approvals, and reject duplicate tournament IDs. Same browser only; no server.
Pending corrections retain the original physical pitch date and count, including during a pause. Daily confirmations update matching athletes across existing tournaments. Concurrent edits are guarded by tournament revisions, but browser localStorage is not a transactional multi-device database. Use one active scoring tab. Backups require exact existing profile IDs; they do not transfer profiles or historical career credit.
